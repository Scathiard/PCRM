# PCRM - Plain Craft Resources Manager

[English](readme.en.md)

面向 Minecraft 玩家和整合包制作者的 Windows 桌面资源管理工具，集中保存光影、资源包、YSM 模型、TaCZ 枪包等资源，让多个实例复用文件并保留各自选定的版本。

## 使用场景

- 同一套模型、枪包或光影需要在多个整合包中使用，减少反复复制和重复占用。
- 整合包升级后，将资源库中的个人资源投放到新实例。
- 同一资源保留多个版本，按实例决定升级或回退。

## 核心特性

- **集中入库**：导入文件或完整资源文件夹，保留外部源文件，同名不同内容的版本分别存放。
- **共享与去重**：同盘使用 NTFS 硬链接，跨盘按需复制到实例所在盘的共享缓存，再由该盘实例复用。
- **存量收编**：扫描已有实例，对比资源内容，确认后将重复文件接入共享资源库。
- **版本管理**：查看历史版本，明确确认后切换，支持转为独立副本。
- **自定义类型**：按实例中的相对目录定义新类型，并设置忽略规则。
- **配置联动**：切换光影和资源包时更新启用引用，继承光影参数，配置更新失败会提示。
- **状态检查**：区分最新共享、旧版共享、独立副本、内容异常和未入库资源。

## 与启动器的关系

PCRM 直接管理实例资源目录，与 PCL、HMCL 等启动器独立配合，不启动游戏，不管理 Mod 的 `.jar` 文件，也不解析模组依赖或下载在线资源。

资源文件共享同一份内容，绕过管理器原地改写共享文件会影响使用它的实例；检测到变化不代表能够恢复被覆盖的内容。
